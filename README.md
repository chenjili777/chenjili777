# AI Data Engineering

I work with behavioral data in fintech, building warehouse tables and defining metrics for acquisition, conversion, and retention. I’m interested in how AI data agents and machine learning systems can reuse those definitions.

- **AI Data Agents** — I prototype and test tools that turn questions about user behavior into SQL. I check whether a funnel query counts the right users and matches events in the intended order.
- **Feature Engineering** — I build reusable feature definitions from event data. Each definition specifies which events count, how far back to look, and what to do when no event occurs.
- **ML Infrastructure** — I’m exploring how to keep training and serving features consistent and how to reproduce a feature using only the data available at prediction time.
